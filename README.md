# Астерия — астрологический портал с гороскопами

Учебная практика УП.09.01 (ПМ.09 «Проектирование, разработка и оптимизация веб-приложений»).
Студент: Паджев Иван Сергеевич, группа ВД-1-23.

## Возможности
- ежедневные и недельные гороскопы для 12 знаков зодиака (общий, любовный, карьера, здоровье, финансы);
- персональная натальная карта: Солнце, Луна и асцендент по дате, времени и месту рождения
  (координаты и часовой пояс города — через Open-Meteo Geocoding API);
- каталог астрологов с фильтром по специализации, отзывы и запись на консультацию;
- статьи и астропрогнозы;
- регистрация, авторизация, личный кабинет;
- административная панель: CRUD для всех таблиц и просмотр 5 представлений (VIEW).

## Технологии
HTML5, CSS3, JavaScript, PHP 8 (PDO), MySQL/MariaDB, XAMPP.

## Запуск
1. Скопировать папку проекта в `C:\xampp\htdocs\asteria`.
2. Запустить Apache и MySQL в XAMPP Control Panel.
3. Импортировать `database/asteria.sql` через phpMyAdmin.
4. Открыть http://localhost/asteria/
